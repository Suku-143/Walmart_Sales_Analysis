# Walmart Sales Analysis

## Project Overview
This project analyzes Walmart Global Superstore sales data from 2012–2015 using Python and Power BI.

## Objectives
- Analyze sales performance by category
- Analyze profit vs discount
- Regional sales analysis
- Customer segment analysis
- Monthly sales trend analysis
- Sales forecasting

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Jupyter Notebook

## Key Insights
- Category-wise sales contribution
- Region-wise performance analysis
- Customer behavior analysis
- Shipping trend analysis
- Sales prediction model

## Project Structure
- Dataset
- Python Notebooks
- Power BI Dashboard
- Project Report
